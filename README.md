**Svar kortfattat på följande frågor om git**:
Vad är skillnaden mellan git add och git commit? 
- Git Add är när man flyttar sina filer till ett så kallat #stageing area# , de finns inte permanent i historiken än. Git - Commit har din fil fått ett unika ID och man har lagt till ett meddelande. 

Varför använder man branches istället för att jobba direkt i main? : Man använder branches för att underlätta ex rättningar, buggtestning eller testning. När det sedan ska publiceras gör man en merge och man publicerar i main grenen. 

Vad händer rent praktiskt när man gör en merge? Då slår man ihop branches. Ex en Dev med en Main branch. 

Vad är skillnaden mellan att pusha till GitHub och att publicera direkt på t.ex. Netlify?: GitHub är mera en lagringsplats medan netlify visar upp din webbplats, sk webbhotell.
